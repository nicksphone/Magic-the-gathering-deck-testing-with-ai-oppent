# Granted attachment acquisition checks

The attachment and forecast modules retain the original 12 paid choice assertions and
48 forecast, style, opacity and delegated Aura controls. They depend on the
single shared `audit/gate2-granted-target` fixture bundle; `DEPENDENCY.json`
checks those three exact inputs before imports. No fixture data is duplicated.
The relative bootstrap path was adapted from the standalone handoff, not the
test assertions or production behavior.

From a local source-only checkout, the repository runner's `composed140` mode
collects all seven modules: the 56 granted-target producer/publication checks,
these 60 AI checks and the original 21 equip plus three attachment checks.
Use the native command and independently sealed source/runtime maps documented
in the shared bundle's README, selecting `composed140`. Keep evidence outside
source and runtime. Do not run SQLite on the archived NFS share.

The guard denies native SQL, socket and child operations before application
imports. Source and runtime hashes, 155 canonical seed rows, RNG, threads and
file descriptors must match afterward. It is not an arbitrary-process OS
sandbox. A checkout containing a database or symlink does not meet that runner
contract; use a clean source-only copy, not deletion of an existing database.

The 13-style controls cover ordinary equip legality, not representative decks
or measured playing strength. The four Aura controls preserve selected pure
function assertions from a mixed module; that original mixed module is not
qualified whole by this bundle. Real game/browser acceptance remains separate.

The two additional whole modules, `test_ai_granted_rollout.py` (4 cases) and
`test_ai_simulation_frontier.py` (12 cases), exercise the shared AI simulation
boundary before opaque conditional acquisition. They preserve actual public
responses, first priority passes and known-card resolution. `composed265` runs
all four AI modules together with the shared producer/compiler suite and six
original backend neighbor modules. This is a deterministic legality/opacity
check, not a statistical playing-strength certificate.
