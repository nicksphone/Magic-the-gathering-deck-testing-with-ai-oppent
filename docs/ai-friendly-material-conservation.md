# Friendly Removal Material Conservation

The shared materializer recognizes only bounded native compound removal trees:
effect_sequence and the supported conditional_instruction schema, with damage,
destroy_permanent, exile and accompanying gain_life leaves. Depth8/node16 or an
unknown child causes abstention before further traversal. Classification never
executes a truncated effect: the original action enters the existing full native
projection and128-step settlement.
The existing conditional-damage fallback remains available when profit is unknown;
it also projects the whole announced action, never a selected sequence fragment.

The destruction baseline remains a three-item tuple. Its private summary captures
that same settled public position without another rollout. Battlefield references
include incarnation and zone sequence. Terminal outcomes, unknown continuations,
baseline-loss rescue, and existing known negative utility precede the optional
comparison. Missing optional information cannot erase an established False.

For an otherwise-positive result, useful creature material lost beyond the settled
baseline is not compensated by own life alone. Saved/gained assets, changed enemy
material, cards, mana, counters, shields, permissions or other recorded resource
changes retain the original utility comparison. Unknown public characteristics or
unresolved future summaries remain None. This is a declared local heuristic, not
a global life price, life cutoff, card-name rule or strategic-dominance theorem.
Existing legacy three-tuple suppliers do not manufacture a material certificate.

Full canonical unit controls cover20life small-body compound exile, enemy retarget,
four-life burn rescue, baseline-doomed material, existing death wins and unknowns.
Synthetic traversal/summary protocols are explicitly labelled and do not invent
native outcomes. Root, offered action and RNG are preserved. Aura entry scoring,
global evaluate_board weights, hand-selection code and model APIs are unchanged.
This edit creates a new source epoch; old snapshots/checkpoints are not retagged.

The final 30-module pure regression gate passed 696 tests and 13 subtests in
339.92 seconds. The separate protected-input damage module passed all 22 tests.
The original missing-input run and the conditional-fallback regression it later
exposed remain historical failures; neither was relabelled as a pass. Tests,
the protected witness and the precollection guard were unchanged. The guard
reported no forbidden I/O attempts. These are source regressions using synthetic
learned-policy protocols, not real-checkpoint, trained-model or natural-game
qualification.
