## Contracts

Private capture version 3 retains first-event physical creature sources,
including owner, controller, sequence and actual effective types. Snapshot
validation requires the exact source/list roster, physical and retained public
observation backing, and original Factory stock binding. It does not require
the source still to be a creature, opposing-controlled or on the battlefield.
Public and decision projections omit all sideboard facts. Older captures stay
playable but incomplete/unknown, never retrospectively certified.

Original stock binding uses actual Factory raw rows, saved printed source
identity and exact face data, not physical-ID prefixes or mutable face names.
The whole entry is protected after use. Missing or unbound non-token source
context makes completeness sticky unknown; only an actual token flag permits
the non-original-stock exception.

The planner consumes validated persisted metadata and completed private/public
history. Known metadata selects the knowledge route; a valid empty plan does
not fall through. Unknown history/metadata declines. The legacy route is
limited to explicitly known offline-seed rows. Incoming spell effects require
whole-clause existing compiler coverage; the only empty-effect exception is
positive membership in the exact preexisting self-counter-prohibition grammar.
`printed_body_gaps` adds checks for its recognized families, not a universal
coverage certificate. The shared predicate extraction preserves the entire
original profile module by exact byte and AST inverse.

Plans conserve main and side stock, preserve the original legal main size
(60 and 64 tested), swap at most three units, and never cut any used stock
entry. Both boards hydrate before either is assigned. Current own-board
creature counts use the engine's effective type query, not printed type lists.
`auto_sideboard` is a strict boolean, defaults true, and only affects AI seats;
false and invalid values have explicit controls.
