# Context-Aware Suspend Diagnostics

Base: immutable published 7f1fa9c source archive, not current parent/main.

`known_unsupported_mechanics` accepts optional `canonical_context`. Only actual
hydrated deck-pair rows and CardService completeness rows pass it. Text-only
callers remain conservative, including existing corpus/report scripts.

The Suspend diagnostic requires recognized local hydration sources, matching
complete Oracle and name, explicit normal/empty layout, no faces, metadata
readiness, and unchanged runtime `instruction`/`PRINTED` admission. The remaining
whole body must be self-named fixed positive damage to any target, fixed targeted
player draw, or a plain Creature with numeric printed power/toughness and no
ability or Flying. Unknown bodies, extra clauses, variable/nonmana Suspend costs,
missing provenance, and other layouts retain the warning. A nonexistent normal
mana cost is legitimate; it is not the Suspend cost and is not invented.

This is a bounded diagnostic shape admission, not arbitrary Oracle recognition,
execution certification, a new compiler, or proof of provenance supplied by
untrusted callers. `exploratory` and `not_certified` labels remain unchanged.
Every other unsupported marker remains independent. Soul-Scar Mage and Searing
Blaze warnings are unchanged. No gameplay, costs, events, or card data changed.

Fixtures are unchanged full primary Scryfall rows in
`backend/tests/fixtures/suspend_canonical`, with printing IDs and source hashes in
`provenance.json`. New boundary strings are explicitly diagnostic adversarial
inputs, not fabricated canonical cards. The original six text-only REDs remain
immutable historical audit evidence outside default collection.

The qualification runner denies SQLite and socket operations before pytest
collection. Actual in-process HTTP preflight uses dependency-overridden read-only
canonical rows, no application lifespan/startup, and no server. It covers both
reported deck positions, helper parity, unchanged active-match inventory, and
`not_certified` versus known unsupported results. It does not qualify live HTTP,
natural game startup, arbitrary Suspend bodies, or data sync.
