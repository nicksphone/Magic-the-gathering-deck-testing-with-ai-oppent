# Variable Suspend Keyword Qualification

This increment is over immutable context-qualified 7f intake source, archive
SHA256 `85e8f96bf126cd66acbb25efd024607e797e80f27193494f0d2f1d51abcee323`.
It is not a qualification of a moving parent or the later Detritivore CDA fix.

## Public ABI And Printed Admission

`SuspendAction.x_value` is an optional top-level strict nonnegative integer.
Fixed instructions reject any non-null value; variable instructions require an
explicit value at execution. Query options describe a required choice, not an
executable default. No spell-target X or historical-paid-X field is reused.

Variable recognition requires one complete printed `Suspend X` line with one
leading `{X}`, the existing fixed mana-token alphabet, and explicit `X can't be
0.`; normal/empty layout, no faces, and Creature type are required. Printed
extra exile-counter abilities remain separate and unqualified. Unknown extra
Suspend/time-counter instructions refuse. No names or body effects are dispatched.

Fixed `PRINTED`, `instruction`, and `diagnostic_surface_admitted` are unchanged.
The original 24 desired tests are copied byte-exact into an ordinary acceptance
module (including their historical docstring), not rewritten or marked xfail.
Historical red logs and the intake's two independent Detritivore stat failures
remain in their original immutable archive, not promoted as release assertions.

## Finite Resource Contract

Variable availability/payment accepts only a finite certificate: strict
nonnegative integer eligible mana pools plus each ready free tap-only source's
maximum actual output bundle. Restricted mana uses the existing Suspend payment
context; creature-cast-only mana cannot pay this special action. Bundled mana
models, paid/resource-changing sources, non-tap free sources, invalid/unknown
amounts, and successful payment beyond the certificate fail closed. Fixed
Suspend keeps its existing payment path and is not subject to this new boundary.

The actual printed-cost payment predicate checks the minimum and finds the
maximum by binary search within the finite certificate. No arbitrary X cap,
unbounded doubling loop, guessed output, or unsupported infinite-mana assumption
is used. Tests include genuine finite pool plus canonical Island/Mutavault,
restricted Somberwald Sage, a 200000 paid X, and explicit planner fault injection.
Complex mana resource models are intentionally unqualified, not capped.

## State And Continuations

Payment places exactly selected X counters and retains priority without a cast
or stack object. Subsequent state records remaining counters, not original X.
Existing snapshots/zone-sequence guards, owner upkeep, counterable last-counter
trigger, optional decline/free cast and haste handling are reused. No serializer
or state fields were added. Both-seat tests check immutable checked_action roots,
actual Stifle casting, intermediate/final snapshots, and stale incarnations.

## Scope And Limits

Full canonical Aeon Chronicler and Detritivore fixtures/provenance are retained
unaltered. This is keyword admission, NOT whole-card certification. Both cards
retain whole-card Suspend warnings; their extra exile triggers and the frozen
base's Detritivore CDA defect remain unresolved. Casting tests stop before
claiming whole creature resolution. New lifecycle fixtures use real canonical
cards in both libraries to avoid the intake fixture's pre-existing failed draw.

All qualification uses a precollection sysaudithook plus patched SQLite/socket
entry points. No SQL/network access, HTTP qualification, AI choice support,
natural App retry, current-parent merge, or live deployment is claimed.
