## Proposed Shared Seam, Not Implementation

Move generation currently has `_can_cast_spell`, which separately requires
own-main timing, instant type, or a flash keyword. Shared
`restrictions.can_cast_in_current_timing` has another non-instant timing floor;
checked engine casts also use this shared query. A single grant added to only
one of these checks would leave the other route inconsistent.

Propose a pure shared spell-casting timing permission query, used by both
admission and checked execution, reading current controlled battlefield
sources and recognized scoped canonical ability text. An unrestricted
"you may cast spells as though they had flash" grant applies to spells, not
land plays or loyalty/other activations, and must not mutate printed or
effective keywords. No card-name dispatch or cached persistent grant.
Recognized prohibitions, split second, zone rules and explicit timing
restrictions outrank a grant; do not bypass them by early return or add a
`during_resolution`/free-cast flag. Preserve existing face/zone restrictions
and intrinsic flash handling. Unknown or scoped permission text must remain
explicitly unqualified rather than broadened into an all-spells grant.

Separately, the compound Savage Beating timing predicate needs generic
conjunctive restriction handling. No production parser/query changes are
authorized or shipped here. The exact source hashes, failure nodes, actual
snapshots, raw fixtures and integration apply proof accompany the report.
