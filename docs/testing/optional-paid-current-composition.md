# Optional land, paid triggers and printed roles

## Scope

Isolated composition based on c5ee7c and the published shared tap-readiness
milestone 0ac863a. Main, live servers and user databases were not modified.
Gameplay remains application code; SQLite stores state and evidence only.

Implemented bounded behavior:

- Explicit private optional hand-land identity or decline, original controller,
  checked continuation and snapshot/restart handling.
- Supported optional trigger payment before reward, resource-aware AI decisions,
  genuine source/controller receipts and unsupported-clause diagnostics.
- Shared effective creature self-tap readiness, including haste.
- Complete printed cast/copy self-pumps with retained source incarnation.
- Shared hand-land ramp classification, without card-name exceptions.
- Minimal GUI hand-land choice/cardinality control, not a UI redesign.

isolated prefix was not used. Tests remained unchanged and ran in a new required
prefix with fresh local SQLite and explicit evidence directory.

## Known Limitations and Next Upgrades

No arbitrary-card, professional AI, whole-suite, real browser, LAN or HTTPS
deployment certification. Two canonical magecraft characterization tests record
missing global as-though-flash support; passing characterization is not a rules
golden. Generic creature observers, compound counter costs, search instructions,
global flash, wider simultaneous events and stronger measured AI remain next
backend work. Special-land metadata and general control-change/animation
episodes require separate acceptance. Main/live deployment remains separate.
