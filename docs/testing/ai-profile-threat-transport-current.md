## Private Estimates

`knowledge_snapshot` accepts an optional `estimates` namespace with exactly
`transport_version`, `root`, `faces`. Version1 root/face entries contain exactly
`tier`, `routes`, `limits`, `printed_inputs`. Tier is an exact int0..3, never a
bool/float/default. Routes retain the existing AnswerRoute effect key, target
zone, targeted flag and conditions. Limits retain estimator limitations and
explicit `known_gap:` entries; unknown support is not a legal-action certificate.

At canonical-row hydration, the selected persisted fields must equal the same
existing `derive_profile` estimator run on genuine full RAW. Each retained
compact printed input must reproduce that estimator's tier/routes/limits.
Inputs retain only name/self-reference, complete Oracle, type, mana and actual
layout/power/toughness when present. No full RAW, artwork, repository/corpus
inventory, rulings text, or global name cache is added. Layout/printed PT are
needed by existing typed coverage/ready-for-match predicates: dropping them
from Archangel of Wrath changes its kicker gap. This is not numeric PT tuning.

Tag-only V1 capsules remain compatible. Valid old tag profiles without numeric
fields still mint a legacy carrier rather than losing their validated tags.
Malformed or semantically forged new estimates cannot yield numeric advice.
Cold `copy_snapshot(..., semantic=True)` rejects resealed numeric/routes/limits
tampering. The pure `estimate_for(card)` returns an immutable ThreatEstimate or
None and revalidates semantics before numerical use. There is deliberately no
unreviewed hot validation cache; this first slice has no scoring caller.
Existing positive tag lookups do not reparse their Oracle text.

Opaque cards are rejected before reading the carrier. Existing indexed-original
face checks, private cold/memory serde and recursive public omission cover the
entire optional namespace without additional model or serializer fields.
The consistency seal is not a signature, client permission, source-execution
grant or loaded-runtime authority.

These 14 baseline cases already pass under unchanged policy. They are not a
