# Native Token/Return Planning

Final review's token-return hold is resolved by an explicit return-candidate guard
and genuine paid-copy regressions. This remains an opt-in component, not an adopted
application runtime or a claim that the AI is finished.

## Reproduced And Corrected

The preceding twelve-source prefix passed on both tested Oven -> Food -> Familiar
and Goose -> Food -> Familiar wins. Separate manual native payment/resolution
controls won. This is a missing two-action planning preference, not a card-rules
implementation failure.

The new forecast reads Forge's loaded token types, complete typed costs, intrinsic
graveyard-return declarations and literal public drain chains. It does not spawn
imaginary cards, move live objects, call a random sacrifice preference, copy hidden
hands or create a hypothetical paid list. The normal native rule, payment, target
and condition gates remain. Every admitted sacrifice-preference tie must work.
Possible consumed resources cannot remain credited as surviving payoff sources.

`TriggerHandler` adds only a current-source visibility query. No native registry,
event or rule body changes. Unsupported replacement, trigger, relevant static,
future-condition or cost semantics withhold the preference. Snow costs are not
estimated from color strings without provenance.

The first implementation still failed Goose2. A post-choice diagnostic identified
native basic-mana `Secondary` metadata and Flying's combat-only `CantBlockBy`

Review found comma-selector, typed future-restriction and consumed-payoff defects.

claimed. The protocol checks RNG, mana-pool and actor-visible continuity. The
separate observer query checks RNG and ability-ID continuity; neither is a blanket
native cache-purity or historical hidden-information certificate.

The final review then found token victims could be credited as future returners.

return-only token exclusion gives **4 PASS**. A token may still fund the return of
a real graveyard card. These four cases retain manual Oven controls and are not
counted as two additional AI-executed two-action wins. The earlier 42-row candidate
and its temporary promotion hold remain separate historical artifacts.

Initial observer compile/face-down-fixture errors and negative-suite foreign-owner

their terminal results; historical frozen artifacts and old Java audits remain
