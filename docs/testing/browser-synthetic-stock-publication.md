different printed identities (15 named poses). Their declared stock cannot
certify those synthetic cards. These calls now explicitly pass
`capture_original_stock=False` to the test-only publisher. Only literal booleans
are accepted. Default publication preserves native capture, including canonical
face stock; malformed bound ownership still rejects. Nothing catches validator
errors or infers permission from an invalid snapshot.

The pure fixture projection helper binds the updated exact fixture function:
removing precisely its ten added keyword arguments recovers the original function
bytes/hash. Its explicit publication flag follows the same unknown-stock rule.
Separately, three original snow/compleated/Memory Deluge tests declare unknown
original stock before intentionally repurposing their Factory cards. All their
gameplay actions, payment assertions, snapshot assertions, and outcomes remain.

First corrected seven-module cohort: 146 passes / 10 failures (seven stale
projection pins and those same three inherited failures). Final seven whole
modules: 158 passes, 0 failures/errors/skips, SQL0, source equality. NEW29 includes
all 15 mutated poses, the actual checked hybrid cast paying three white lands,
native v3/canonical faces, forged-owner rejection, strict flag types, and
unauthorized fixture-body rejection. HTTP/SQL publication boundaries are inert
in these pure source projections; actual browser qualification is separate.

Production, main, validators, physical cards, Oracle text, costs, rules, and the
original browser driver are unchanged. This is synthetic test setup repair, not
natural-game capture qualification or a sideboarding-certificate recovery.
