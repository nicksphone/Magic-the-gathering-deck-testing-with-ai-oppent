# Post-Denial Speculation

This component builds on f9b3d123506c0a204785fc0aacdd85d1509520eb.
Only five strategic planner methods in agent.py change. The existing shared
combat allowance remains Master128 / MasterPlus256, with no cache or rule change.

Sticky denial is unknown, not a low score or an empty completed search.
Private speculative line/state/stack work raises UncertainSimulation after
denial. The root catches only the scoring invocation and only stops on confirmed
denial, retaining previously completed native-checked candidates. Preparation
stops before another materialization. A final successful token is still usable.

The shared shortlist has a private keyword-only opt-in used only by its two
stack-planner callers. Its default learned-policy route and live materialization
remain available after denial. Ordinary non-budget uncertainty retains existing
handling. No global materializer or fallback guard is added.

The new test module uses complete canonical card rows and checked paid casts.
It includes counted dependencies to isolate cancellation boundaries, both-seat
native lethal/fallback and hidden-order controls, and the actual learned adapter
with synthetic in-memory scores (no checkpoint, learned-body reads or NN).

Agent mutation is not assumed equivalent: a counted real-bookkeeping witness
measures default pass-history/knowledge deltas 3/2 versus aborted 0/0. The default
materializer recursively chooses a main-phase continuation. This is control-flow
evidence, not a claim every materialization has those deltas. Retained root292
measurements separately record actual decision knowledge and persistent history.
