## Primary Rules And Narrow Proposal, Not Implemented

Official https://media.wizards.com/2026/downloads/MagicCompRules%2020260925.txt
was freshly archived. CR603.6c distinguishes from-anywhere zone triggers from
leaves-battlefield triggers; 603.10a identifies look-back cases. Thus do not
repurpose the LKI dies matcher or let battlefield Humility suppression suppress
the new graveyard object's from-anywhere ability. CR113.8 assigns controller
from the source when triggered (owner if it has no controller). A foreign-owned
card in its owner's graveyard needs owner-controlled trigger publication.
CR603.3b governs APNAP/publication before the next priority opportunity; costs
must finish before the owner-trigger response window, not immediate replacement.

Propose separate future ownership, not changes in this artifact:
1. A once-only, committed actual graveyard-entry event at the shared executor,
   with real origin/owner/new sequence/source identity; no event for replacement
   destinations library/exile. Preserve full prevalidation and existing LBF/dies/
   discard/mill ordering. Do not collect twice through aliases. Direct death/
   combat/keyword bypass routes remain separate unqualified migration work.
2. Anchored complete generic self from-anywhere clause collection against the
   new graveyard object and its active ability, not departed LKI; retain actual
   clause/source reference, owner and a real triggered stack object through
   existing staging/APNAP machinery. Short self-reference must follow the
   source's actual printed-name reference, not a Kozilek production exception.
3. Generic compiler/resolver for complete owner-shuffles-their-graveyard body.
   Bind non-target owner at trigger creation; at RESOLUTION move the CURRENT
   graveyard contents, preserving existing graveyard-departure observers and
   exact zone transitions, then dispatch one real library shuffle with retained
   triggered resolving-item causality. Cards exiled in response stay exiled;
   countered trigger causes no shuffle. Use existing layer/target/source rules,
   not a fake static receipt or a whole-graveyard immediate replacement.
