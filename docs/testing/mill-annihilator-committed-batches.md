prepared before ANY removal, then the retained plans execute. An early printed
replacement shuffle cannot replace the second selected card with a newly read
top card. Genuine entry receipts publish through the existing batch emitter
only after all selected movement commits; existing mill events/logs remain.
This follows multi-object mill in official CR701.17a/608.2f, not sequential
single-card mill instructions. Separate instructions still form separate actions.
Official [2026-09-25 CR](https://media.wizards.com/2026/downloads/MagicCompRules%2020260925.txt)
raw bytes, URL/effective date and SHA accompany evidence.

batch LBF. During selected movements the existing private sink stores genuine
PRE/POST entry receipts, published after complete commit and before existing
sacrifice/dies batches. No forged StackItem, announcing spell cause or event.
