# Exiled Time-Counter Bodies

Bounded component extension over frozen V7, not whole-card readiness. Complete printed
`Whenever a time counter is removed from this card while it's exiled, ...` clauses
admit only fixed draw and targeted (nonbasic) land destruction. Names are irrelevant.
Unknown tails/layouts/faces and multi-counter body multiplicity stay explicit unsupported.
All original canonical Oracle, IDs, printed costs/stats and coverage warnings are retained.

A genuine single-counter removal queues an independent owner-controlled body using the
existing generic event/order/target machinery. The last removal also queues Suspend's
optional casting permission; neither replaces the other. Source identity/colors/types
are captured from the real exiled object before stack assembly. Real Stifle can counter
either ability separately; Counterspell of the later creature does not counter its
already-triggered body. No AI, SQL/schema, API/cost/serializer or transport change.

Baseline new30:26 ordinary failures/4passes; first product:new30passes. Supplementary
strict tests exposed existing frozen dependencies, not permission to expand scope:
- Same-ID animated Mutavault/Cloudshift reentry: targeted destruction currently lacks
  a target generation receipt. `_remember_trigger_target` only captures one for
  exile-until-source-leaves effects. A separate additive proposal is NOT applied.
- Detritivore full-creature resolution: frozen nonbasic-graveyard CDA selector remains
  defective; parent already has a separate repair. Two strict full-body goldens stay
  red here, while Aeon full-body/cleanup-haste goldens pass both seats.
- Ghostly Flicker is not admitted by this frozen engine. Its two desired controls
  remain ordinary-red outside release collection; no forged blink effect substitutes.

Do not promote this component as target-reentry-safe until the separate reference hunk
is authorized and its unchanged strict tests pass. Do not clear whole-card warnings or
claim Detritivore full-body qualification before the independent CDA dependency is
composed and tested. Historical keyword-only tests assuming no body trigger remain
unchanged and are reported as transition failures, not silently weakened.

Original HTTP30 is NOT rerun for this pure extension. V7's 30PASS transport/lifecycle
receipt remains immutable and applies to its original frozen source only. New pure
runs deny native SQLite and every socket audit event before pytest collection.
