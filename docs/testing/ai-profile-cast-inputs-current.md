# Profile-driven cast priority: bounded rules-core qualification

This increment is based on public `46158ddb40a2e67e27a37c0854eba8d2bc05a281`.
It consumes existing match-frozen numeric estimates in production cast bias,
without new coefficients, card-name policy branches, rules or target authority.
It does not complete Task2.3 or establish measured AI improvement.

## Implemented inputs

- For eligible creature deployments, validated tier>=2 replaces the printed
  cmc>=4 classification limb. Prospective effective power>=4 remains. The
  existing prospective-entry ability reader makes suppression/type changes
  unavailable advice, including genuine Humility on the battlefield.
- Control/Midrange premium-removal slots retain the existing2.0 coefficient.
  Ordinary productive opponent targets use tier>=2 OR current big/lethal
  pressure. Eligible low-pressure tier0/1 targets do not receive that premium.
  Current PT, keywords, live mana/recurring engines and lethal terms remain.
- The priority helper reads original offered opponent BF references and reuses
  existing productivity/covered masks and creature/noncreature threat scores.
  It never changes the actual menu, chooses a real action or calls the full
  materializer/friendly choice projection. Explicit opponent selection is
  retained; actual self-removal intent and self-winning logic are unchanged.

Missing/malformed/stale/opaque/mismatched/suppressed advice returns unavailable,
not tier0. Exact old premium/classification branches remain the fallback.
Unknown/missing cost proof, non-base costs, modes/conditional/compound effects,
non-BF/foreign/friendly explicit targets and unresolved stack/choice contexts
remain unavailable. Base cost proof reuses the actual cost-option renderer.
Source printed-surface consistency must be persisted/matching too; stale or
unprofiled spell sources keep old scoring. This additional consistency check
is not a signature, full-card admission or execution permission.
