# AI Casting Resource Opportunity

## Contract

AI materialization compares a bounded set of explicit delve/convoke/improvise
payments and deliberately empty payment against the original engine fallback.
Every alternative is validated and applied to a detached planning copy through
the existing rules engine. Authoritative state, logs, RNG and canonical data are
not changed by the decision. Previously supplied explicit choices are untouched.

The heuristic penalizes losing usable attackers/blockers, repeatable mana and
graveyard cards with future permissions or recursion payoffs. It values actual
supported self-tap token triggers and affordable own-hand follow-ups. Creature
stats use effective engine stats; tapping an assigned blocker does not remove it
from combat. The same capability-based policy serves each archetype.

Queries reuse only within an unchanged, synchronous state scope and return
independent choices. Opponent hand/library identities are not read. The normal
AI affordability helper now passes the actual card and source identity into
shared mana/resource legality.

## Evidence

- Ten initial canonical both-seat cases failed before implementation.
- Twenty-three focused cases pass, including four-archetype blocker retention, delve
  flashback retention, improvise mana preservation, actual tap-trigger rewards,
  query-copy isolation, hidden-opponent identity invariance, explicit choices,
  lightweight card views and combined hybrid convoke/delve without spending mana.
- An earlier overlapping selection passes 342 tests across information boundaries, mana forecasts,
  recurring engines, resource payments and tap/graveyard events.
- A cache test initially assumed tied choices must be explicit. It now uses a
  canonical flashback-retention position with a genuinely superior alternative;
  the legal fallback was not weakened or forced to lose ties.
- A broader strategy run exposed a pre-existing lightweight-view assumption in
  the newly called keyword helper. The shared query now accepts missing Oracle
  metadata as empty, preserving existing non-resource policy behavior. Its
  overlapping rerun passed 377 cases; subsequent final coverage is separate.
- Resource-event predecessor 16da9fa passes its full 8,627-test backend and
  complete browser gates. Those results do not qualify this changed AI.

## Limits And Next Gates

- Run exact-source full backend and browser/natural replay qualification.
- The search is bounded (ordinary fallback plus at most 16 explicit alternatives),
  not exhaustive optimization. Broaden swap/color/compound-cost alternatives and
  measure marginal runtime against decision quality on actual retained positions.
- Approximate follow-up scores are not guarantees that two spells can both be
  cast or that an opponent has no response. Optional/targeted rewards and unusual
  permissions still need broader fixtures.
- Selection370 completed twelve repeated executions/six unique paired-seat samples
  across Drain/Tribal, Tokens/Ramp and Tempo/Control without determinism failures
  or unresolved outcomes. Three unique traces change versus the old baseline.
  Tempo/Control seat-two decision 524 exposes questionable early interaction
  reservation; fix the generic timing policy in a separate tested batch.
- Preserve unchanged canonical decks/seeds. Neither tiny outcomes nor heuristic
  scores establish expert strength, balance or arbitrary-card completeness.
