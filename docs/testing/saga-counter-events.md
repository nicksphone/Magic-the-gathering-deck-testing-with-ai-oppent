# Saga Counter Events and Chapter Ordering

## Implemented Scope

Turn-based precombat lore placement uses the shared scalar counter resolver with
non-effect provenance. Effect-only doubling does not initially apply; another
replacement can make it applicable. The affected player chooses competing order.
The active player's supported Saga placements finish as a staged batch, including
durable continuations when a placement pauses. No priority or SBA interrupts it.

Physical lore changes emit a shared event, so registered lore effects also trigger
every crossed chapter threshold. Grouped printed symbols such as I, II expand
into separate chapter abilities. Supported parsing covers I through X, not
arbitrary chapter syntax or all chapter effects. These boundaries follow
[Wizards' Saga rules 714.2-714.4](https://media.wizards.com/2026/downloads/MagicCompRules%2020260619.pdf).

Chapter abilities use the normal ordering and target-choice pipeline, including
ward and target revalidation. Final-chapter sacrifice waits for original chapters
on the stack or awaiting staged publication/human order. It does not wait for
unrelated abilities or copies. New metadata distinguishes battlefield
incarnations. Older saved chapter labels remain recognized, but those snapshots
lack sufficient provenance to distinguish an old incarnation with certainty.
Final sacrifice uses the existing sacrifice/death/zone-replacement path.

The API exposes lore as a public named counter without changing private snapshot
storage. Both battlefield lanes and hover previews display it. Temporary subtype
buffs no longer require an additional keyword-granting phrase to be parsed.

## Bounded AI Improvement

The AI layer orders entirely friendly token-creation/team-buff groups so relevant
creatures exist before a snapshot buff resolves. It uses effect data and subtype
compatibility, not card names. Explicit human ordering is preserved. Mixed or
unknown effects, negative buffs, unrelated subtypes and opponent token creation
are left untouched. This is a measured local dependency improvement, not a
general simultaneous-trigger planner or professional-play certification.

## Known Limitations and Next Upgrades

Intrinsic lore on entry, read ahead and projected pre-entry characteristics need
the unfinished general entry-replacement packet design. Arbitrary chapter effects,
multiple/optional chapter targets, gained/suppressed chapter abilities and full
multi-kind/proliferation coverage remain open. Compound/mixed AI trigger ordering
needs broader state-aware search and independent decision-quality evaluation.
Long-session, network and clean-machine release gates are not closed here.
