# Selected blocker mana pricing

This scoped Task 2.3 correction changes only `AIAgent._block_bias` over the
reviewed block-material agent preimage `3a22186bba3ea4275acb4aff4b7d759c5206faebdb5a55430e592eda51f59985`.
It prices the unique chosen blockers instead of every offered mana creature.
The existing no-resource materializer supplies the allocation. The existing
`simulation_checked_action` validates a fresh normalized copy, including current
pairing restrictions, payments, requirements, and blocker capacity. An invalid
or uncertain allocation keeps the complete legacy offered-source tariff.

Known empty allocations retain the existing `-0.8` sentinel. Selected effective
mana sources retain the existing `3.5` tariff; actual printed-ability suppression
removes that source's tariff, while an unavailable mana reader preserves the
selected source's legacy raw predicate. Neither legal menus nor chosen actions
are filtered. Nonempty offered-profit math, lethal pressure, archetype terms,
coefficients, combat rules, and other agent methods are unchanged.

## Limits

Canonical creatures occupy trusted existing-board/counter fixtures, not paid
birth episodes. Actual decisions and independently checked safe alternatives
are genuine rules-core actions; malformed replies and type-surface probes are
explicitly inert protocol controls. No SQL, HTTP, provider, SDK capture, or D13
allocation was used. No new weights, combat model, parser, or card-name policy
was added. This does not complete general numeric block migration, the existing
nonempty offered-profit estimate, full Task 2.3, strength benchmarks, or A/B
nonregression across seeds/seats. Parent composition and independent peer review
remain separate from this component evidence.
