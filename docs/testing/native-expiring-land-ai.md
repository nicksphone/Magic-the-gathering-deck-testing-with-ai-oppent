# Native Expiring-Land Source Choice

## Reproduced And Corrected

The six-archetype baseline exposed a Tempo turn that played a hand Island while
an identical Iteration-exiled Island expired unused. A separate registered native
fixture pays the real UR, resolves the complete canonical Iteration partition,
then invokes ordinary Default once before diagnostics. In both seats it chooses
the hand Island; an explicitly manual native alternative proves the exile Island
is legal and playable. Manual controls are not AI successes.

The availability/deduplication path retains the exile land. LandPlanner collapses
identical name/tapped-entry alternatives, and the fallback's equal-score maximum
keeps the first candidate, ordinarily from hand. The correction retains every
existing score calculation and caches it once. Only equal-score alternatives can
replace that original maximum, using proven expiring access as a secondary
preference. Both/neither urgent preserve original order. Combo selection,
LandPlanner, earlier returns, native legality and payment remain unchanged.

## Permission Boundary

The land, permission host and creator host must pass actor visibility and
face-down guards before new body inspection. All applicable zone-granting
permissions must come from immutable command-zone Effects with actual Effect
creator provenance and default or explicit current end-of-turn duration.
Persistent, other-duration, unknown or mixed longer-lived grants prevent an
urgency classification. This does not invent an expiry from an arbitrary static
ability or from descriptive text.

This changes the fallback, not a complete land planner. Equal native scores are
heuristic equality, not universal strategic interchangeability. Origin-sensitive
interactions, planner/combination choices and broader multi-card planning are not
certified by this component.
