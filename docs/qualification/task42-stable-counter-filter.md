## Narrow Product Change

Only `AIAgent._choose_action` changes. No scoring weights, new methods,
card-name branches, engine permissions, card source, or rules parser change.
The existing low-dynamic-value counter filter remains intact; it gains an
alternative for printed-low advice only when all of these are true:

- One genuine opposing spell occupies the original single-stack window.
- Archetype is Control or Counter-heavy.
- Own life exceeds eight, an explicit conservative safety gate, not a tuned
  score weight or a terminal-safety certificate.
- Existing public board role is converter/control and all opposing
  permanents are proven intrinsic lands; no hidden card identity is inspected.
  The proof reuses existing strategic-leaf semantics: effective Land but not
  Creature, string Oracle with no non-reminder body, nonempty effective type
  line, an actual basic land subtype, and positive tap-only mana outputs.
  Readiness is ignored so a genuinely tapped payment Forest remains intrinsic.
  Effectful/nonintrinsic, unknown, engine, and animated/creature permanents
  stay legacy; not all zero-creature boards are qualified as stable.
- The existing late inevitability horizon is not active.
- The existing knowledge service supplies a valid semantic estimate,
  `_printed_major_threat` returns exactly False, and known gaps, uncertain
  triggers, unaccounted paragraphs, or unknown numeric payloads are absent.
- The existing `printed_body_gaps` checker reports no recognized-family gaps.
- The full RAW Oracle body, trimmed only for surrounding whitespace, is empty
  vanilla, or exactly free tap-only fixed
  mana text. `_fixed_only_mana_text` anchors every line; every parsed cost must
  equal `{T}`, tap-only outputs must be positive, and the entire body must equal
  templates derived from the existing typed fixed-mana vectors. Those templates
  contain only `Add`, mana symbols, and punctuation, never unknown raw tails.
  Arbitrary parenthetical text is not removed from this coverage proof. The
  existing rules-engine reminder normalization and intrinsic-land gate are
  unchanged; this is a conservative source-creature filter, not a rules change.

Llanowar's printed profile labels its activated mana as uncompiled in the

advice keeps the original dynamic path. Printed answer routes never grant

authoritative. No new filter applies to abilities or multi-stack windows.
