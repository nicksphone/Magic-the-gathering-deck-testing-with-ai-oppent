The next unexecuted whole module has 22 cases and 22 original serializer child
launches. Qualify its actual retained-source/announced-X actions and subprocess
roundtrips while preserving the original script, assertions and private bodies.
The user has authorized continued RC work; this is the agent's test-instrumentation
choice, not a new product preference, data waiver or release acceptance.

Use the established pure replay instrumentation with an exact admission for
the native restart helper and its three calling case families. Before native
Popen construction, validate the original command/kwargs/environment and copy
the environment to prepend the early guard. Validate native code signatures
under plain active Python assertions. Preserve the exact `-c` script and argv.

independently of return code. Bind new controlled inputs by metadata only;
only the original serializer script may read their bodies. No guard, verifier
or reviewer reads/hashes/copies snapshots, models, locks or database bodies.

the child with an in-process serializer would lose the test's process check.
Neither satisfies this task. Exact native-call admission is the chosen approach.

is the one unchanged whole module, not TCP/cold HTTP, a game, AI strength or RC.

normal direct reap and explicit absence of the newly owned process group.
