existing checked replay loop, not an independent game engine.
Base: immutable 46158ddb40a2e67e27a37c0854eba8d2bc05a281. No agent/rules/main,
persistence, D13 or shared-root edits. No actual games/SQL under this grant.

## Files And Interfaces
- Modify backend/scripts/regression_matrix_replay.py: optional run_match
  game_runner; run_game trace_builder(state,pid,legal,completed_action,decision),
  budget and record_game(result,raw_log). No-hook default behavior unchanged.

  cases with actual source-function projections and inert engine doubles.
- Create docs/testing/task31-bo3-runner.md: exact contract and remaining gates.

## Execution
1. Write NEW tests first. Missing functions/signatures must be strict assertion
   failures, not import/fixture errors. Record RED under a precollection fence.
2. Implement scheduler/export and narrow replay hooks. Preserve actual outcomes
   regardless of sink return; writer failure means unavailable evidence and stop.
   Interrupted state keeps last accepted raw trace, never fabricates a winner.
3. Run the whole NEW module (no selectors). Verify legacy projection parity,
   source preservation/reversal and default callback argument absence.
4. Update owned graph AST-only; retain original graph/map provenance. Freeze
   sparse public delta, pre/post source hashes, raw logs/exits and reverse proof
   on mounted writable NFS; independently read back every archived byte.

## Review Focus
- Equal-value bool/int seeds/quantities reject, duplicate/missing roster rejects.
- Sideboards retained, including nonempty inventories; fixed_no_swaps explicit.
- Draw0 consumes slots; winnerNone or error stops, never transitions onward.
- RAW and normalized hashes separate; sink must not override outcome or claims.
- DQ absent/truncated/unknown remains NULL; Wilson denominator completed series.

## Qualification Limits
Pure source projections use inert state/engine doubles; not paid/native games.
Existing replay, timing, series, manifest and resource-budget modules include
actual engines/storage imports. Whole mixed modules require separate parent IO
review; do not prune their tests to manufacture whole-module coverage. Parent
must qualify a genuine two-deck BO3, trace parity, data, writer/budget/resource
closure before actual matrix execution. Schedule counts are not executed games.
