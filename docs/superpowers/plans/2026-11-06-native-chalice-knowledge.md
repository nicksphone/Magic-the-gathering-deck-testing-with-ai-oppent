# Native Chalice Knowledge Boundary

The upstream Forge `PermanentAi` Chalice branch counts physical opponent
cards with a predicate that excludes the hand. The frozen eight-case native
audit demonstrates different first Default choices for equal actor inputs,
registered deck disclosures and incoming RNG state on both seats.

## Implementation

1. Preserve the original audit and add native goldens for unknown face-down
   exile, known spent cards, returned cards and genuinely granted recasting.
   Run these against the unchanged baseline before product edits.
2. Replace hidden physical-zone counting with registered main-deck knowledge
   adjusted only by observer-identifiable spent originals. Do not read hidden
   identities, disable Chalice, use timing-sensitive `canPlay` as future
   eligibility, or erase useful public information. Reuse native APIs.
3. Admit exactly nine sources and sixteen classes in profile schema 7: the
   complete bounded-worker schema 6 composition plus `PermanentAi`. Synthetic
   shape and publication tests must first fail, then pass; preserve all older
   profile contracts and runtime resource limits.
4. Independently rebuild the changed class, compare all unchanged class bytes,
   run original/new native cases and affected preservation controls. Record
   baseline errors, policy failures, candidate failures and synthetic cases
   separately. A source review is advice, not execution proof.
5. After controlled qualification, run one fresh, bounded built-UI game using
   the composed profile. No seed search, forced result or private trace
   publication. Preserve evidence on verified NFS before local cleanup.

## Alternatives And Limits

`Library || Hand` is insufficient because it can read identities hidden in
other zones. An unadjusted registered histogram loses legitimate public spent
card knowledge. The selected implementation must preserve both privacy and
that knowledge. Ambiguous copy or provenance data must not become a hidden
identity oracle. Registered-list disclosure is an explicit upstream policy
premise, not proof of unrestricted opponent knowledge.

No broad AI completion, live adoption, durable-save or best-of-three claim is
made by these component checks. Current RC CI is left undisturbed while live.
