# Display Targets And Selected Faces

Native legal-move hints may expose `targets` as a list of public candidate
descriptors. That presentation list is not an action's selected-target mapping.
Decision-frame aliasing must retain and walk the list without treating it as
the receiver of a mapping lookup.

`_selected_face` preserves the existing order: an explicit top-level face
(including zero), otherwise a nested face in a target dictionary, otherwise
the main face zero. Absent targets and presentation lists have no nested face.
Other target-field types are rejected rather than hidden by a falsy default.
This reader neither mutates nor converts a target list into a selected action.

Complete-action normalization and the public action models remain unchanged.
A presentation list, scalar, malformed face, or unsupported field is not made
into a valid selected action by this change. No feature schema, reference
library, numerical encoder, Q/V math, model header, or engine rule is changed.

The portable regression uses full existing canonical Forest, Elvish Mystic,
and Shuko rows from the hash-pinned source-linked-exile fixture. Trusted unit
setup relocates the genuine factory-born objects; legal equip hints come from
the original rules engine. Both seats exercise actor-public projection,
frame construction, symbolic state/action encoding, reference roundtrip and
input/RNG purity. Separate malformed protocol controls cover precedence and
unchanged strict selected-action validation. No private game snapshots or
paths are embedded in the public tests.

The observed pre-fix portable gate had eight failures and twenty-one passing
controls, including the exact native equip-list traceback on both seats.
Private historical-position reproduction is a separate NoNN diagnosis, not
new game outcomes, training data, strength evidence, or a checkpoint update.
Historical UNKNOWN attempts remain UNKNOWN; immutable older-source training
captures remain their own source epoch. Passing this component does not prove
that every policy decision or future game completes within its budget.
